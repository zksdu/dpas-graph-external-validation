# DPAS-Graph external validation: zero-shot RNA-to-protein prediction under a fully held-out protocol

Code and archived result tables for the manuscript
*"Zero-shot RNA-to-protein prediction survives external validation but trails linear baselines"*
(submitted to **Communications Biology**).

The repository contains (1) the model source, (2) every analysis / evaluation /
figure-generation script used in the paper, and (3) the **archived result tables**
(all CSV/JSON) from which every headline number in the manuscript was computed.
No raw imaging or sequencing data is redistributed; all inputs are publicly
available (see *Data sources*).

## Key result (reproducible from this repo alone)

Under a fully external protocol on GSE263617 (all four sections held out,
31-marker panel), the published dual-relation graph model DPAS-Graph reaches
mean per-protein Spearman **0.145–0.147**, while a ridge regression on
transcriptomic PCs reaches **0.388** under the identical protocol; a second
published graph architecture (DGAT, Nat Commun 2026) reaches **0.341**
(ridge wins 21/31 markers). Three independently seeded full-budget retrainings
give 0.274 ± 0.029, with the external isotype floor at 0.103 ± 0.004.
A shallow non-linear MLP baseline (0.346 ± 0.015 across three seeds)
sits between the graph models and ridge, ruling out linearity of the
competitors as an explanation.
A matched-spot DGAT re-run (uniform spot sets, no panel-internal
filtering) collapses DGAT to 0.240 -- on par with DPAS-Graph itself --
showing the reference-pipeline gap (0.341) was a spot-set artefact.
See results_server_final/dgat_uniformqc/.

You can verify the manuscript numbers directly:

```bash
python scripts/paper_number_audit.py        # 150 automated checks, 0 expected failures
python scripts/independent_recheck_v2.py    # independent end-to-end recheck
```

Both scripts read only the CSV/JSON tables shipped in this repository
(`results/`, `runs/`, `results_server_final/`, `server_round2/`,
`gse_external_summary_100ep.csv`) — no GPU, no model weights, no raw data needed.

## Repository layout

```
DPAS-Graph/               model source (adapted from the published DPAS-Graph code;
                          --seed parameterisation and LODO two-fold driver added)
scripts/                  all pipeline, evaluation, aggregation and figure scripts
server_round2/            DGAT same-protocol comparison (adaptation script + result tables)
results/                  archived result tables (CSV) and all figures (PNG, 600 dpi)
runs/                     per-fold training metrics (per_protein_metrics.csv, summaries)
results_server_final/     100-epoch budget runs: same layout as runs/
gse_external_summary_100ep.csv   sample-level external evaluation (100-epoch checkpoints)
DGAT_panel_31.txt         the frozen 31-marker evaluation panel (verbatim for both architectures)
```

## Environment

Training was performed on a single NVIDIA RTX 6000-class GPU (CUDA 12.x) with
Python 3.10; the model environment is documented in `DPAS-Graph/environment.yml`.
Core dependencies for evaluation / figures / audit:

```
pandas, numpy, scipy, matplotlib
anndata, scanpy          (placenta/decidua analyses)
torch, torch_geometric   (training and DGAT comparison only)
```

See `requirements.txt` for the pinned list used locally.

## Data sources

| Dataset | Role | Source |
|---|---|---|
| GSE263617 | External validation (4 Visium CytAssist sections, 35-plex protein panel + isotypes) | NCBI GEO [GSE263617](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE263617) |
| Placental/decidual snRNA-seq atlases & Visium sections | Training and application cohorts | Zenodo [doi:10.5281/zenodo.8159511](https://doi.org/10.5281/zenodo.8159511) (Nonn et al., *Hypertension* 2025) |

The external cohort was rebuilt from public SpaceRanger matrices under a
documented coordinate-integrity protocol (`scripts/external_eval_gse.py` and
`scripts/external_eval_gse_100ep.py`).

## Reproduction pipeline (outline)

1. **Preprocess** the public cohorts and build graph datasets
   (`scripts/assemble_pe_h5ad.py`, `DPAS-Graph/scripts/`).
2. **Train / LODO** (`DPAS-Graph` runner with `--seed`; driver:
   `scripts/run_lodo_100ep.sh`, `scripts/designB_run_all.sh`).
3. **External evaluation** on GSE263617
   (`scripts/external_eval_gse*.py`, `scripts/competitor_benchmark.py`,
   `server_round2/dgat_run.py`).
4. **Aggregate** (`scripts/multiseed_aggregate.py`, `scripts/designB*_aggregate.py`,
   `scripts/internal_vs_external.py`).
5. **Audit & figures** (`scripts/paper_number_audit.py`,
   `scripts/independent_recheck_v2.py`, `scripts/make_*.py`).

Every figure PNG in `results/` is regenerated by the corresponding
`scripts/make_*.py` from the archived CSV tables — no values are hard-coded.
