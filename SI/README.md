# Supplementary Information (SI)

This directory contains the Supplementary Information of the manuscript:

- `SI_Note_A1_number_audit_104checks.md` — Supplementary Note A1: the full 150-row manuscript number-consistency audit (regenerated by `python scripts/paper_number_audit.py`, currently 143 PASS / 0 FAIL), the proposed RNA-to-protein reporting standards, and the versioned appendix records (multi-seed extension, correction record, MLP/Wilcoxon additions, matched-spot DGAT rerun);
- `SI_Table_S1.csv` ... `SI_Table_S15.csv` — the 15 supplementary tables;
- `SI_Fig_S1_isotype_floors.png` — Supplementary Figure S1 (marker vs isotype-control Spearman distributions).

The Word assembly of the SI (as submitted) is `SI_Combined.docx` in the authors' submission package; this directory is the source-of-truth, machine-readable version.
